# Cerulea — Product Definition

Cerulea is a deployment and operations platform for blockchain and infrastructure systems.

It is not a code generator and not just a no-code builder.

Cerulea enables users to configure, deploy, and operate:

- public blockchain networks (for dApps)
- private blockchain networks (enterprise/government)
- supporting infrastructure
- runtime environments
- operational governance layers

Cerulea Studio is the configuration interface within the Cerulea platform.

The core value of Cerulea is:
deployment + operations + lifecycle management of real systems.

## Primary user groups

- dApp developers
- enterprises
- governments

The system must assume non-technical users are interacting with it.

All flows must be understandable without developer knowledge.

## Deployment targets

Cerulea deploys:

- blockchain runtime networks
- private networks
- public networks
- infrastructure environments
- runtime artifacts

Code generation is NOT the output.

Deployment is the output.

## Deployment philosophy

Cerulea must:

- deploy real infrastructure
- deploy real runtime environments
- operate systems continuously

Cerulea must not:

- simulate deployments
- produce fake runtime environments

## Studio pathways (critical)

All Studio workflows depend on pathway selection:

### Public chain pathway
Used by:
- dApp developers

Outcome:
- deploy onto shared Cerulea public network

### Private chain pathway
Used by:
- enterprises
- governments

Outcome:
- deploy dedicated blockchain networks
- client hosted runtime

This decision affects every subsequent step.

## Platform surfaces

Cerulea includes:

- public site
- authentication system
- dashboard
- documentation
- Cerulea Studio (subdomain)
