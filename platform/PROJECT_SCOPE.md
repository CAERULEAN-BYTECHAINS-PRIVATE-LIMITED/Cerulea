# Cerulea — Project Scope

Cerulea is a deployable platform with multiple required surfaces:

1) Public site (main domain)
- Homepage (separately editable; may be reworked by freelancer later)
- Marketing pages (as needed)

2) Auth system
- signup, login, logout
- forgot/reset password
- profile/account pages
- protected routes and session handling

3) Dashboard (authenticated)
- post-login landing
- navigation to Studio and user resources

4) Documentation
- public docs pages

5) Cerulea Studio (subdomain)
- hosted at `studio.<domain>`
- step-based builder
- draft persistence
- real Gemini-based AI assistant

Even if some parts are not implemented yet, the system should be designed to support all of them cleanly.
